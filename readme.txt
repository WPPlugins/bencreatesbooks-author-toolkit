Books and Events post types, detail fields, and the setup wizard for the AuthorPress theme.

== Description ==

BenCreatesBooks Author Toolkit is the content engine for the AuthorPress theme. It adds:

* A **Books** post type with a Genre taxonomy and detail fields: subtitle, buy link, price, per-retailer buy buttons, reviews, and book quotes
* An **Events** post type with date, time, venue, city, and link fields, for readings, signings, and launches
* A **guided setup wizard** under Books, Setup Wizard: import the demo content in one click, or build the site step by step with your own books, bio, and pages

Keeping post types in a plugin means your books and events survive a theme switch, untouched.

== Installation ==

1. Upload the bencreatesbooks-author-toolkit.zip file under Plugins, Add New, Upload Plugin, and activate it.
2. Open Books, Setup Wizard to import the demo or run the guided setup.
3. Add your books under Books, and your appearances under Events.
